## Shared prompt framework

> Create one original vertical 3:5 full-bleed Leo × MBTI tarot card. Use the Leo master only as a strict style and layout reference: bone-ivory and antique-gold Art Nouveau frame, amber and black cathedral stained glass, radiant sun crown, great lion-profile halo, laurel leaves, stage-like beams, floating gold dust, crisp ink, flat cel-shaded anime rendering, aged mosaic/crackle texture.
