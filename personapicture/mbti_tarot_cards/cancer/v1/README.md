## Shared prompt framework

> Create one original vertical 3:5 full-bleed Cancer × MBTI tarot card. Use the Cancer master only as a strict style and layout reference: bone-ivory and moon-silver Art Nouveau frame, deep navy and tide-blue cathedral stained glass, full-moon crown, crab-shell halo, pearl and seashell ornament, stylized curling waves, crisp ink, flat cel-shaded anime rendering, aged mosaic/crackle texture. Keep the complete main subject and every ornate border visible. Fill the whole card with artwork. Use lunar tides, shells, pearls, protective claws, harbor and sanctuary motifs; never use Aries ram, Taurus bull, or Gemini twin emblems.

> No words, letters, numbers, initials, MBTI labels, zodiac names, signatures, watermarks, logos, gibberish, pseudo-writing, title strip, bottom whitespace, caption, plaque, cropped limbs, duplicate body parts, malformed anatomy, extra people, photorealism, 3D rendering, watercolor, or chibi styling.
